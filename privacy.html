プライバシーポリシー / Privacy Policy

最終更新日 / Last updated: 2026-10-30

取得する情報

Calendar-Sync は、利用者が許可した Google アカウントのカレンダーの予定（タイトル、日時、場所、会議リンクなど）とメールアドレスを、Google Calendar API を通じて読み取り、利用者自身の別のカレンダーに予定を作成・更新・削除します。

情報の保存と共有

取得した情報と認可のトークンは、利用者の Mac の中（macOS のキーチェーンとローカルのファイル）にだけ保存します。開発者のサーバーや第三者に送ったり、共有したり、販売したりすることはありません。広告や分析には使いません。

Google ユーザーデータの扱い

Google API から受け取った情報の利用と他アプリへの転送は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

削除

利用者は Google アカウントの「サードパーティ製のアプリとサービス」 からいつでもアクセスを取り消せます。ツールの logout コマンドで、保存したトークンも削除できます。

Calendar-Sync reads calendar events and the email address of Google accounts the user authorizes, via the Google Calendar API, and creates, updates or deletes events in the user's own other calendars. Data and tokens are stored only on the user's own Mac (macOS Keychain and local files). Nothing is sent to, shared with, or sold to the developer's servers or third parties, and nothing is used for advertising or analytics. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at https://myaccount.google.com/permissions.
