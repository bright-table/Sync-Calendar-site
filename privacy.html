プライバシーポリシー / Privacy Policy

最終更新日 / Last updated: 2026-11-11

このポリシーは、macOS のカレンダーアプリ Sync Calendar（シンクカレンダー）（旧名 Calendar-Sync）に適用されます。

取得・利用する情報

  • Google カレンダー（Google Calendar API）：利用者が許可した Google アカウントのカレンダーと予定（タイトル、日時、場所、説明、会議リンク、公開設定、色など）を読み取り、利用者自身のカレンダーに予定を作成・更新・削除します。カレンダーどうしの予定のコピーと、ToDo から予定を作るときに使います。
  • Google ToDo（Google Tasks API）：利用者が許可した Google アカウントの ToDo リストとタスク（タイトル、メモ、期限、完了状態、並び順など）を読み取り、利用者の操作に応じてタスクを作成・更新・完了・移動・削除します。アプリの ToDo パネルでの表示と編集、カレンダーへの予定の作成、ほかの利用者自身のカレンダーへの「TODO：」の予定のコピーにだけ使います。
  • アカウントの情報：どのアカウントかを見分けるために、メールアドレスを使います。

情報の保存と共有

取得した情報は、利用者の Mac の中だけで扱います。認可のトークンは macOS のキーチェーンに保存し、設定と同期の記録は利用者の Mac のローカルのファイルに保存します。開発者のサーバーはなく、情報を開発者や第三者に送ったり、共有したり、販売したりすることはありません。広告や分析には使いません。人がデータを読むのは、利用者本人だけです。

Google ユーザーデータの扱い（Limited Use）

Sync Calendar が Google API から受け取った情報の利用と他アプリへの転送は、Google API Services User Data Policy に従い、Limited Use の要件を守ります。Google のユーザーデータは、上に書いた利用者向けの機能を提供・改善するためにだけ使い、広告への利用、第三者への転送や販売、AI・機械学習モデルの学習には使いません。

アクセスの取り消しと削除

利用者は Google アカウントの「サードパーティ製のアプリとサービス」 からいつでもアクセスを取り消せます。同期ツールの logout コマンドや、macOS のキーチェーンの項目の削除で、Mac に保存したトークンも削除できます。アプリを削除し、Mac のローカルのファイルとキーチェーンの項目を消すと、Mac に残る情報もなくなります。

Privacy Policy (English)

This policy applies to Sync Calendar, a macOS calendar app (formerly Calendar-Sync).

  • Google Calendar (Google Calendar API): reads the calendars and events (title, time, location, description, conference links, visibility, colour, etc.) of the Google accounts the user authorizes, and creates, updates and deletes events in the user's own calendars. Used to copy events between the user's own calendars and to create events from tasks.
  • Google Tasks (Google Tasks API): reads the task lists and tasks (title, notes, due date, completion status, order, etc.) of the Google accounts the user authorizes, and creates, updates, completes, moves and deletes tasks at the user's request. Used only to show and edit tasks in the app's task panel, to create calendar events from tasks, and to copy tasks as private "TODO：" events to the user's own other calendars.
  • Account information: the email address is used to tell the accounts apart.

All data is handled only on the user's own Mac. Authorization tokens are stored in the macOS Keychain, and settings and sync records in local files on the user's Mac. There is no developer server; nothing is sent to, shared with, or sold to the developer or any third party, and nothing is used for advertising or analytics. No one other than the user reads the data.

Sync Calendar's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only to provide and improve the user-facing features described above, and is not used for advertising, transferred or sold to third parties, or used to train AI or machine learning models.

Access can be revoked at any time at https://myaccount.google.com/permissions. The sync tool's logout command, or deleting the items in the macOS Keychain, removes the tokens stored on the Mac.
